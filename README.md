# 🤖 KidArduino Studio (MVP)
### Çocuklar İçin AI Destekli Görsel Arduino Stüdyosu

Proje dosyaları `kid-arduino-studio/` klasöründedir.

Detaylı dokümantasyon, kurulum ve kullanım yönergeleri için lütfen [kid-arduino-studio/README.md](file:///C:/Users/hkizildag/Desktop/arduino-ide/kid-arduino-studio/README.md) dosyasını inceleyin.

## 🚀 Hızlı Başlatma
```bash
# 1. Backend:
cd kid-arduino-studio/backend
pip install -r requirements.txt
python main.py

# 2. Frontend:
cd kid-arduino-studio/frontend
npm install
npm run dev
```
Tarayıcınızda: `http://localhost:5173`
